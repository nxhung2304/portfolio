## Description

Add a dark/light theme toggle to the site header and apply Tailwind's `dark:` modifier across all pages and components. The user's preference should survive page reloads via `localStorage`.

---

## Acceptance Criteria
- [ ] Dark mode toggle button is visible in the header on all screen sizes (header bar is always rendered — no separate mobile placement needed)
- [ ] Clicking the toggle switches between light and dark themes with a smooth `transition-colors` animation
- [ ] Dark mode preference is persisted in `localStorage` and restored on page load
- [ ] All pages (Home, About, Projects, ProjectDetail, Blog, BlogDetail, Contact) render correctly in dark mode
- [ ] System preference (`prefers-color-scheme`) is respected as the initial default when no `localStorage` value exists
- [ ] Zero flash of wrong theme on initial load — achieved via inline script in `index.html`, not `onMounted`

## Step-by-step Guide

**Files to create/modify:**
- `index.html` — inline `<script>` in `<head>` for no-flash init
- `tailwind.config.js` — add `darkMode: 'class'`
- `src/style.css` (or global CSS entry) — add `transition-colors duration-200` globally
- `src/composables/useDarkMode.ts` — shared reactive state + toggle logic
- `src/components/DarkModeToggle.vue` — inline SVG button, match `LanguageToggle` style
- `src/components/Header.vue` — add `<DarkModeToggle />`, apply dark: classes
- `src/components/Layout.vue` — dark: background
- `src/components/Navbar.vue` — dark: mobile menu
- `src/pages/*.vue` — dark: classes on all 7 pages

**Key decisions:**
- `darkMode: 'class'` strategy — user overrides system pref via toggle
- `dark` class lives on `<html>` (`document.documentElement`), not `<body>`
- No-flash via inline script in `index.html` — runs synchronously before any JS bundle loads; `onMounted` approach is not acceptable
- Composable state is **module-level** `ref` (outside the function body) so all callers share the same reactive instance
- `DarkModeToggle` button styled to match `LanguageToggle`: same border, padding, hover states — see `src/components/LanguageToggle.vue` for reference classes
- Transition: apply `* { transition-colors: ... }` globally in CSS so every element animates, rather than sprinkling `transition-colors` on each component
- `prose-invert` applies **only** in `BlogDetail.vue` on the `prose` wrapper, toggled conditionally — blog list page has no prose content

**Non-obvious snippets:**
```html
<!-- index.html <head> — must be before any <script type="module"> -->
<script>
  (function() {
    var stored = localStorage.getItem('theme')
    var prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches
    if (stored === 'dark' || (!stored && prefersDark)) {
      document.documentElement.classList.add('dark')
    }
  })()
</script>
```

```ts
// src/composables/useDarkMode.ts
const isDark = ref(false) // module-level — shared across all callers

export function useDarkMode() {
  function init() {
    isDark.value = document.documentElement.classList.contains('dark')
  }
  function toggle() {
    isDark.value = !isDark.value
    document.documentElement.classList.toggle('dark', isDark.value)
    localStorage.setItem('theme', isDark.value ? 'dark' : 'light')
  }
  return { isDark, init, toggle }
}
```

> `init()` reads the class that `index.html` already set — no duplication of localStorage logic.

**Common dark: pairs to apply across pages:**
- `bg-white` → `bg-white dark:bg-gray-900`
- `bg-gray-50` → `bg-gray-50 dark:bg-gray-800`
- `bg-gray-100` → `bg-gray-100 dark:bg-gray-800`
- `text-gray-900` → `text-gray-900 dark:text-gray-100`
- `text-gray-600` → `text-gray-600 dark:text-gray-400`
- `text-gray-500` → `text-gray-500 dark:text-gray-400`
- `border-gray-200` → `border-gray-200 dark:border-gray-700`
- `shadow` / `shadow-sm` — keep as-is (shadows are subtle in dark mode)

## Notes
- `index.html` inline script must come **before** `<script type="module" src="/src/main.ts">` — order matters
- `DarkModeToggle` button: copy `LanguageToggle`'s outer button classes and swap flag SVGs for sun/moon SVGs; the `group-hover:scale-110` micro-animation on the icon is a nice touch to match
- No 404 page exists in the router — out of scope for dark styling
- `@tailwindcss/typography`'s `prose` class has its own color system; `prose-invert` is the official dark variant — do not override prose colors manually
