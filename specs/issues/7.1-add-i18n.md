## Description
Add bilingual support (English and Vietnamese) to the portfolio using `vue-i18n`. A language toggle button is placed on the left side of the header (before the logo), allowing visitors to switch locales at any time. All user-facing text in shared components and page views should be translatable.

## Step-by-step Guide

**Files to create/modify:**
- `src/i18n/index.ts` — create i18n instance, load locales, read/write `localStorage`
- `src/i18n/locales/en.ts` — English messages object
- `src/i18n/locales/vi.ts` — Vietnamese messages object
- `src/main.ts` — register `app.use(i18n)`
- `src/components/LanguageToggle.vue` — toggle button (EN / VI)
- `src/components/Header.vue` — add `<LanguageToggle />` left of logo, switch nav labels to `t()`
- `src/components/Navbar.vue` — update mobile nav labels to `t()`
- `src/pages/*.vue` — replace hardcoded user-facing strings with `t()`

**Key decisions:**
- Use `vue-i18n@9` (composition API mode, compatible with Vue 3)
- Store locale in `localStorage` key `'locale'`; fall back to `'en'`
- Nav links stay as route objects in `constants/nav.ts`; labels become i18n keys (e.g. `nav.home`) — the `label` field can be removed or kept as fallback
- Toggle sits **left of the logo** in the flex row; on mobile it stays visible (not inside Navbar hamburger)

**Non-obvious snippets** *(only if needed)*:
```ts
// src/i18n/index.ts
import { createI18n } from 'vue-i18n'
import en from './locales/en'
import vi from './locales/vi'

const savedLocale = localStorage.getItem('locale') ?? 'en'

export const i18n = createI18n({
  legacy: false,          // use Composition API
  locale: savedLocale,
  fallbackLocale: 'en',
  messages: { en, vi },
})
```

```vue
<!-- LanguageToggle.vue – minimal example -->
<script setup lang="ts">
import { useI18n } from 'vue-i18n'
const { locale } = useI18n()
function toggle() {
  locale.value = locale.value === 'en' ? 'vi' : 'en'
  localStorage.setItem('locale', locale.value)
}
</script>
<template>
  <button @click="toggle" class="text-sm font-medium px-2 py-1 rounded hover:bg-gray-100">
    {{ locale === 'en' ? 'VI' : 'EN' }}
  </button>
</template>
```
