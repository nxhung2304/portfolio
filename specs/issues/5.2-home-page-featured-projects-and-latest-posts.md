## Step-by-step Guide

**Files to create/modify:**
- `src/pages/Home.vue` — Integrate the new sections and handle data fetching.
- `src/components/ProjectCard.vue` — Ensure it supports the layout needed for the home page (can be reused).
- `src/components/BlogCard.vue` — Ensure it supports the list layout variant if needed.

**Key decisions:**
- **Data Fetching:** Fetch data in `onMounted` within `Home.vue` and pass to sub-components.
- **Sorting:** Projects should be ordered by `created_at` descending; Posts by `published_at` descending.
- **Visuals:** Use the `shimmer` and `float` animations from `home.jsx` for consistency.

**Non-obvious snippets**:
```ts
// src/pages/Home.vue - Example queries
const fetchFeatured = async () => {
  const { data } = await supabase
    .from('projects')
    .select('*')
    .eq('featured', true)
    .order('created_at', { ascending: false })
    .limit(3)
  return data
}

const fetchLatest = async () => {
  const { data } = await supabase
    .from('posts')
    .select('*')
    .eq('published', true)
    .order('published_at', { ascending: false })
    .limit(3)
  return data
}
```
