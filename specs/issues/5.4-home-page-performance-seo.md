## Description
Optimize the Home page for performance and search engine visibility. This includes ensuring efficient data fetching from Supabase, implementing asset lazy-loading, and setting up proper SEO metadata.

---

## Acceptance Criteria
- [ ] No N+1 queries to Supabase when fetching featured projects and latest posts.
- [ ] Images in "Featured Projects" and "Latest Posts" sections use lazy-loading.
- [ ] SEO meta tags (title, description, og:image) are correctly set for the home page via `useHead`.
- [ ] Home page passes basic performance tests (Lighthouse/DevTools).
- [ ] All internal and external links on the home page are functional.

---

## Implementation Checklist
- [ ] Audit `Home.vue` and its child components for Supabase query efficiency.
- [ ] Ensure `FeaturedProjects.vue` and `LatestPosts.vue` fetch data in single batches.
- [ ] Add `loading="lazy"` attribute to thumbnails in `ProjectCard.vue` and `BlogCard.vue`.
- [ ] Implement `useHead` in `Home.vue` with appropriate metadata.
- [ ] Run a local Lighthouse audit and address any obvious performance bottlenecks.
- [ ] Verify all links on the Home page (Nav, Social, CTA, Cards) are correct.

## Step-by-step Guide

**Files to create/modify:**
- `src/pages/Home.vue` — Add `useHead` and audit logic.
- `src/components/FeaturedProjects.vue` — Verify efficient fetch.
- `src/components/LatestPosts.vue` — Verify efficient fetch.
- `src/components/ProjectCard.vue` — Add `loading="lazy"` to images.
- `src/components/BlogCard.vue` — Add `loading="lazy"` to images.

**Key decisions:**
- Use native `loading="lazy"` for image optimization as it's simple and widely supported.
- Use `@vueuse/head`'s `useHead` to manage metadata, following the project convention seen in `About.vue`.

**Non-obvious snippets**:
```ts
import { useHead } from '@vueuse/head'

useHead({
  title: 'Home | Portfolio',
  meta: [
    { name: 'description', content: 'Welcome to my portfolio website showcasing my projects and blog posts.' },
    { property: 'og:title', content: 'Home | Portfolio' },
    { property: 'og:description', content: 'Explore my latest projects and read my latest blog posts.' },
    { property: 'og:image', content: '/og-image.jpg' } // Replace with actual OG image path
  ]
})
```

## Notes
- `og:image` should point to a static asset in the `public/` folder or a full URL.
