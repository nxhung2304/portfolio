## Step-by-step Guide

**Files to create/modify:**
- `src/pages/Home.vue` — Main page container.
- `src/components/HeroCanvas.vue` — Interactive particle system.
- `src/components/TerminalText.vue` — Typing effect component.
- `src/router/index.ts` — Route registration.

**Key decisions:**
- **Canvas optimization**: Use `requestAnimationFrame` for smooth 60fps particles. Handle resize events to keep the canvas sharp.
- **Typing effect**: Use `setInterval` or `setTimeout` with a string slicing technique.
- **Mobile responsiveness**: Stack content vertically on mobile, horizontally on tablet/desktop if avatar is used.

**Non-obvious snippets**:
```vue
<!-- TerminalText.vue snippet -->
<script setup>
import { ref, onMounted } from 'vue'
const text = ref('')
const fullText = "building scalable systems..."
onMounted(() => {
  let i = 0
  const timer = setInterval(() => {
    text.value = fullText.slice(0, ++i)
    if (i >= fullText.length) clearInterval(timer)
  }, 60)
})
</script>
<template>
  <span class="font-mono text-blue-400/70">
    > {{ text }}<span class="animate-pulse">_</span>
  </span>
</template>
```
